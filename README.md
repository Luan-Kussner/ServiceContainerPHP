# Service Container em PHP

Este projeto demonstra um Service Container simples em PHP, similar ao Laravel.

## 🧠 Como funciona

- O `Container` usa **Reflection** para descobrir as dependências de uma classe.
- Ele instancia essas dependências automaticamente.
- Inversão de Controle (IoC) na prática!

## ▶️ Como executar

```bash
composer dump-autoload
php public/index.php
